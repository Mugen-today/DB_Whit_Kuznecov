# Резервные копии

Папка сама не создаёт копии и не входит в автоматический график резервирования.
Рабочая MongoDB хранится в именованных Docker volumes, а не в этой папке.
Текущая конфигурация — одноузловой replica set rs0; наличие rs0 не заменяет backup.

Подробная процедура, различия хоста/Bash, логическая копия и проверка восстановления
на отдельной установке: [общая инструкция, раздел 11](../../docs/OPERATIONS.md).
Не копируйте живые файлы WiredTiger обычным копированием каталога. Архив БД,
.env/секреты и config-том требуют защищённого хранения и не должны попадать в Git.
Служебный том GPKG не входит в логический mongodump MongoDB; сохраняйте его отдельно,
если нужно продолжение незавершённого импорта. Данная поставка не добавляет команду
автоматического backup/restore.
