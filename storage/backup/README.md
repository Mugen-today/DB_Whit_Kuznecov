# Резервные копии

Каталог зарезервирован для выгрузок mongodump. Наличие каталога не означает автоматического резервного копирования. MongoDB хранит рабочие данные в именованных Docker volumes, а не здесь.

Для согласованной копии standalone MongoDB остановите прикладные записи на время выгрузки. Секреты не помещайте в команды/архив репозитория. Проверяйте восстановление на отдельном томе до признания копии пригодной. Не копируйте файлы живого WiredTiger обычным копированием каталога.
