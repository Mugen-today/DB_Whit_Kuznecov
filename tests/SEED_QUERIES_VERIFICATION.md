# Проверки версии с исходным Excel и восстановленным окном

10.11.2026.

Выполнено:
- 51 unit-тест Python и три JavaScript-набора; синтаксис/JSON проверены.
- Контроль SHA256 исходного Excel, входящего в поставку.
- Конфигурация Compose с профилями connections/import и монтированием data/.
- Полная загрузка комплектного Excel в настоящую временную MongoDB 8.0.34:
  141831 исходная строка в cases, 37662 Patient, 37662 Instances, 14233 Geodata.
- Повторный запуск seed: количество документов не изменилось, проверочная правка
  сохранилась. Маркер успешной загрузки записан только после окончания импорта.
- Все 100 адаптированных запросов выполнены в mongosh.
- Все 100 результатов независимо проверены Python-вычислениями: фильтрация,
  группировка, соединения, статистика и ссылки. Для top-10 возраста учтена
  неопределённость порядка при одинаковом возрасте.
- Qt/PyQGIS 3.40.6 offscreen: восстановленное окно, подключение, выбор Geodata,
  загрузка страницы со 100 точками и геометрией.
- На выборке исходных документов: редактирование Patient через восстановленное окно
  с явным заполнением отсутствующего паспорта; создание полного нового набора
  через ту же кнопку. Проверки без передачи паспорта закономерно отклоняются.
- Временные MongoDB и backend работали с включённой авторизацией после bootstrap.

queries/RESULTS.md — таблица всех проверок; queries/results.json — машиночитаемый итог.
Полные результаты с индивидуальными строками оставлены вне поставки.

Не выполнено:
- фактическое развёртывание Docker-контейнеров: среда запрещает доступ к демону;
- интерактивная проверка на пользовательских Windows/macOS;
- визуальное сравнение скриншотов по пикселям. Основная компоновка окна взята из
  setup_interface исходного плагина, с изменёнными параметрами подключения и
  дополнительными кнопками.
