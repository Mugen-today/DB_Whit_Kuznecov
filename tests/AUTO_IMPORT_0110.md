# Проверка автоматического импорта 0.11.0

17.11.2026. Импорт независим от инициализации. Исходные файлы в поставку не входят.
Новый путь: scripts/import_data.py → одноразовый контейнер → auto_import.py →
дисковый SQLite preflight → пакетные insert-only операции MongoDB.

Проверены 110 unit-тестов Python и три набора JS mock-тестов. Новые тесты проверяют
распознавание JSON, GeoJSON, GPKG без карты полей, геометрию, сохранность исходника,
повтор без новых ID и неоднозначные связи с архивированием обеих исходных строк.
Синтаксис/JSON проверены scripts/check_project.py, ZIP плагина пересобран с 0.11.0.

Реальные предоставленные файлы проверены на одноразовой MongoDB 8.0.34 с rs0,
аутентификацией, схемой и ролями проекта. Использовались полные файлы, не выборки:

| Источник | Исходные строки | Patient | Instances | Geodata |
|---|---:|---:|---:|---:|
| testB_normalized_final.json | 4276 | 4276 | 4276 | 4276 |
| test_datasetA_ispr_1.xlsx | 217144 по всем листам | 37662 | 37662 | 14233 |

Первый вспомогательный лист Excel содержит исходную таблицу и архивируется в cases;
он не удваивает нормализованных пациентов. Отсутствующие Geodata для строк без
координат не создаются. Неразрешённые ссылки и неверные типы отражаются в полном
отчёте, исходные значения остаются в cases. Уникальные ключи нормализованных
сущностей не меняются при повторе. Точные итоги повторной записи и проверки FK
сохранены в AUTO_IMPORT_NATIVE_SUMMARY.txt этой поставки.

Новый путь предназначен для исторической совместимости: пустые passport/age
допустимы моделью хранения, но дают предупреждения; интерактивные строгие правила
API остаются прежними. Ошибочные значения не заполняются фиктивными данными.
При неоднозначности одно-значных FK связь исключается с явной диагностикой,
оригинальный граф сохраняется в архиве. Это не утверждение, что исходный набор
стал полностью корректным по бизнес-правилам.

Примерные GeoJSON/GPKG тесты синтетические. Произвольный файл с неизвестными
названиями клинических атрибутов автоматически понять невозможно; поддерживаемые
контракты и ограничения перечислены в docs/AUTO_IMPORT_0110.md. FeatureCollection
читается в память целиком, JSON-массив и таблицы — итеративно; общего лимита строк нет.

Полный Docker-запуск не проверен: daemon недоступен в среде выполнения. Консольный
launcher проверен по синтаксису, функциональность адаптера — нативно с настоящей
MongoDB. QGIS/dashboard API не менялись, кроме номера версии; GUI-регрессия новой
поставки отдельно не запускалась. Предыдущие отчёты относятся к своим версиям.

Не подключались и не изменялись рабочие Docker volumes. model.json, роли,
конфигурация томов и обычный запуск без датасетов сохранены. Автоматический
импорт выполняет insert-only, без обновлений/удалений. При позднем сбое записи
подтверждённые пакеты остаются, повтор дозаполняет отсутствующие ID. Общего отката
файла и защиты от конкурентного удаления внешними инструментами нет.
