# Проверки версии Backend — 10.11.2026

## Выполнено

- Дважды: 47 Python unit-тестов, без пропусков в окружении с зависимостями.
- Три JavaScript mock-набора: bootstrap, миграция, настоящий verify.js на модели БД.
- Синтаксис Python/JS, JSON, состав поставки; docker compose config --quiet.
- Два полных цикла настоящей MongoDB 8.0.34 и backend HTTP.
- В каждом цикле: инициализация схемы/ролей на standalone, перезапуск с авторизацией
  и ключом replica set, автоматическая инициализация rs0 через provision.js.
- Все восемь обязательных полей проверены по отдельности: отсутствие любого поля
  даёт 422. Также проверено удаление каждой из четырёх групп.
- Создание координатного и полного адресного набора; ссылки сверены напрямую в MongoDB.
- Последовательный и параллельный повтор одного request_id без дублей.
- Изменение содержимого запроса с прежним UUID даёт 409.
- Проверки гостевого токена, закрытых коллекций, отсутствующего токена, чужого владельца.
- Правка пациента; конфликт устаревшей ревизии; отказ при пустом обязательном поле
  и попытке изменить идентификатор.
- Искусственная ошибка валидатора последней коллекции Foci: весь набор откатывается,
  количества документов во всех коллекциях остаются прежними.
- Старые пути создания отдельной точки и импорта GPKG больше не создают документов.
- Ответы статистики и связанной выгрузки dashboard проверены по HTTP.
- Настоящий PyQGIS 3.40.6, Qt offscreen: создание слоёв/таблиц всех доступных
  коллекций, выбор строки Patient, отправка правки из окна плагина, подтверждение
  возраста через API и непосредственное чтение MongoDB.
- Повторный перезапуск MongoDB после записей: число пациентов сохраняется.

Тесты используют временные каталоги и отдельную MongoDB, не пользовательскую БД.
В native-тесте на время перехода standalone → replica set MongoDB запускается без
авторизации только для начального bootstrap. Все HTTP/GUI проверки идут после
перезапуска с включённой авторизацией и с прикладными учётными записями.

## Не выполнено

- Полная сборка/развёртывание Docker-контейнеров: доступ к сокету демона запрещён
  средой (operation not permitted). Успех docker compose config не доказывает запуск.
- Windows/macOS и интерактивный сеанс QGIS на компьютере пользователя.
- Нагрузочный benchmark и измерение ускорения. Индексы, пагинация, проекция и кеш
  реализованы, но количественное ускорение не заявляется.
- Новый интерфейс Streamlit визуально не проверялся; его Python-синтаксис и backend
  endpoints проверены. HTTP backend и GUI QGIS проверялись фактически.

## Повтор проверки

С установленными backend/requirements.txt и Node.js:
python scripts/manage.py test

С Docker:
python scripts/manage.py integration
python scripts/manage.py integration

Дополнительный native regression: tests/integration/native_records.py.
Задайте MONGOD_BINARY, MONGOSH_BINARY и QGIS_PYTHON (Python с PyQGIS).
Основной Python должен иметь backend-зависимости.
Сценарий требует свободных localhost-портов 27917 и 8000 и создаёт только
временные данные. Двоичные файлы MongoDB и зависимости не включены в архив.

версий, их показатели не следует считать результатами текущей строгой загрузки.
