# Проверка импорта Version_20 / 0.11.1

17.11.2026. Основа — последняя доступная в этом чате версия 0.11.0. Отдельный
архив локальной папки Version_20 не предоставлялся. Исправления выполнены в этой
поставке: Excel по умолчанию читает все листы, добавлен import_json.py, общий
launcher и backend поддерживают --dry-run/--apply. Без флага только проверка.
Прежний плоский импорт сохранён как import_excel_records.py. Все разделы README
сохранены, новая инструкция дополнена Compass, внешними путями и диагностикой.

## Выполненные проверки

113 Python unit-тестов и три набора JS mock-тестов прошли. Новые тесты проверяют
режим по умолчанию, явный apply, взаимоисключение флагов, пути с пробелами,
read-only mount, отсутствие обязательного --sheet и несколько листов без вставок.
AST/JSON/JS проверены check_project.py. ZIP плагина пересобран с версией 0.11.1.

На настоящей одноразовой MongoDB 8.0.34 с аутентификацией/rs0 выполнен
`tests/integration/import_cli_modes.py`: внешний XLSX Patient/Geodata и вложенный
JSON. Реальные backend CLI-процессы выполнили dry-run, apply и повторный apply.
Dry-run не изменил MongoDB, apply создал документы, повтор не добавил новых.

Сравнивались количества всех коллекций Schema до/после, включая cases. Они
не изменились. Подтверждение — IMPORT_CLI_NATIVE_SUMMARY.txt. Исходные файлы не
включены в ZIP. Полная запись обоих образцов ранее проверена в 0.11.0; алгоритм
адаптации сохранён. Новые флаги apply проверены на синтетической интеграционной
фикстуре; полная повторная запись реальных образцов новой версией не выполнялась.

model.json, спецификация ролей, Compose, имена volumes и штатный manage.py
побайтно совпадают с 0.11.0. Рабочие volumes не подключались. Dry-run не вставляет
ни нормализованные документы, ни исходные строки в cases. Apply использует
прежние пакеты по 250 и insert-only ID. Существующие правки не перезаписываются.
Исторические NULL/ошибки полей и неоднозначность FK остаются в полном отчёте;
фиктивных значений нет, строгий интерактивный API не ослаблен.

Docker daemon недоступен в этой среде. Полный Docker-launcher/GUI новой версии
не запускались: launcher проверен модульно, backend CLI — с реальной MongoDB.
После обновления выполните config/up/verify/status с прежним .env и volumes.
Общий откат файла не добавлен: при позднем сбое ранее подтверждённые пакеты
остаются, повтор дозаполняет отсутствующие ID. README явно описывает эти границы.
