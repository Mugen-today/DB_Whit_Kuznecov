# Проверка QGIS-версии — 10 ноября 2026

Использована приложенная GIS-MongoDB-merged(1).zip. Сохранены актуальная схема Instances/Foci, роли MongoDB и существующие ETL-модули. Первая интерактивная интеграция ограничена Geodata.

## Фактически выполнено

- 38 Python unit-тестов и три JS-набора прошли. Синтаксис Python/JS и JSON, комплектность проверены.
- Docker Compose 2.40.3 выполнил config --quiet для базовой, локальной и изолированной тестовой конфигурации с новыми API-токенами.
- Два независимых цикла с настоящим MongoDB 8.0.34, mongosh 2.14.0, PyMongo 4.19.0 и PyQGIS 3.40.6. Созданы новые временные базы, выполнены bootstrap/provision/verify, проверки BSON/RBAC, backend HTTP, миграция и перезапуск.
- В каждом цикле PyQGIS использовал настоящий QgsNetworkAccessManager, memory provider, GeoPackage writer и OGR reader. Окно плагина открывалось в offscreen-режиме с тестовым iface. Изменение через его модальное окно подтверждено прямым чтением Geodata в MongoDB.
- Проверены создание через QGIS HTTP-клиент, повтор request_id без дублирования, сохранение Longitude/Latitude/Elevation, серверный _owner_id, увеличение revision, конфликт устаревшей ревизии, запрет записи Guest и изменения чужой точки, неверные координаты и пагинация.
- После удаления слоя из проекта действие редактирования корректно предлагает новую загрузку. initGui/unload добавляют и удаляют QAction. GeoPackage прочитан через OGR с сохранением объекта.
- Дополнительный qgis_http.py прошёл в обоих циклах. Он включён в Docker integration как qgis-http-probe.
- В финальных циклах подтверждение запроса создания через Qt HTTP заняло 11,3 и 9,1 мс на тестовом хосте. Это отдельные наблюдения, а не нагрузочное измерение.

Исправлены ошибки, выявленные во время проверки. Ошибочный вызов isReadOnly в тесте заменён на readOnly. В плагине исправлено обращение к удалённому слою. После сохранения показывается именно подтверждённая сервером точка, даже если она не попадает на первую страницу общего списка. Из прежнего интеграционного сценария убрана повторная запись имён томов в .env.

## Границы проверки

Docker-демон не работает в этой среде из-за запрета Unix-сокетов. Образы и взаимодействие контейнеров не запускались. Для проверки MongoDB вне контейнера использована временная копия бинарного файла с заменой пути отсутствующего sysfs CPU-файла на локальный файл. В копиях скриптов /opt и DNS Docker заменены локальными путями и loopback. Эти адаптации не входят в поставку.

Реальный QGIS GUI проверялся через PyQGIS offscreen и тестовый iface, без ручной установки в настольный профиль пользователя. Установочный ZIP содержит корректные __init__.py, metadata.txt и код плагина. Проверки Windows/macOS и подключение к настоящим контейнерам остаются для целевой машины и GitHub Actions.

Токены этой простой версии представляют двух фиксированных серверных субъектов, user и guest. Все владельцы QGIS_USER_TOKEN действуют от одной идентичности. Прежние маршруты объединённого API требуют отдельной общей авторизации перед удалённым развёртыванием. Исходные вопросы корректности GeoPackage-импорта и прямоугольных административных границ описаны в docs/MERGE_NOTES.md.
