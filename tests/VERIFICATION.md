# Проверка версии — 6 ноября 2026

- Два прогона по 38 Python-тестов и три набора JS с имитацией MongoDB. Проверены также синтаксис и комплектность проекта.
- Compose 2.40.3 принял базовую конфигурацию, локальный и аварийный режимы, Compass и изолированную конфигурацию интеграции через config --quiet.
- Два цикла на MongoDB 8.0.34 и mongosh 2.14.0. В каждом использована отдельная пустая база. Выполнены bootstrap, provision, verify, чтение и запись с проверкой ролей, HTTP-проверка backend с PyMongo, предварительный план миграции, двукратное применение, проверка перенесённых ObjectId и проверка данных после перезапуска.
- Для запуска вне контейнеров временная копия MongoDB читала описание CPU из локального файла вместо отсутствующего sysfs. В копиях скриптов подставлены локальные пути монтирования и loopback вместо DNS Docker. Эти адаптации ограничены тестовой средой и в поставку не входят.

Полное Docker-развёртывание остаётся обязательной проверкой перед выдачей. При попытке запустить Docker и manage.py integration среда отклонила создание Unix-сокета с operation not permitted. Сборка образов, сетевой обмен между контейнерами, Docker healthcheck и Compass через опубликованный порт в этой среде не проверены. Workflow GitHub Actions подготовлен для штатного запуска и двух независимых интеграционных прогонов.
