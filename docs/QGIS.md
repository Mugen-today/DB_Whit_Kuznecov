# Работа в QGIS 0.8.0

Основная пошаговая инструкция: [STUDENT_GUIDE.md](STUDENT_GUIDE.md), этапы 8–18.
Архитектура и ограничения: [OPERATIONS.md](OPERATIONS.md). Движение большого GPKG:
[GPKG_BULK_080.md](GPKG_BULK_080.md).

Устанавливайте dist/qgis_mongodb.zip, а не весь архив проекта. Обновляйте backend
и плагин вместе; при подключении проверяйте backend: 0.8.0. Используйте HTTP-порт
8000 и API-токен профиля, а не порт/пароль MongoDB.

Все доступные коллекции загружаются полным обходом страниц. Geodata — Point
EPSG:4326, остальные — непространственные таблицы. Слой — memory cache; после
восстановления геометрии и при новом сеансе перечитайте данные. Обычные правки
фиксируются только после подтверждения backend. Создание — форма/GPKG; пользовательское
удаление документов не предоставлено. Экспорт GPKG — штатные средства QGIS.

При импорте дождитесь проверки всех строк, затем отдельно подтвердите запись.
«Продолжить после прерывания» использует сохранённый job и реальные подтверждённые
строки. Пакет не является пределом файла. Подробные примеры mapping — в практикуме.
