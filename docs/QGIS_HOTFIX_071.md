# GIS-MongoDB 0.7.1: Geodata, консоль и импорт GPKG

11.11.2026. Доработка версии 0.7 без изменения архитектуры, model.json,
исходных наборов, имён коллекций и Docker volumes.

## Обновление

Обновите файлы backend и плагин одновременно. Сохраните прежний .env в корне проекта.
Не выполняйте init повторно, не удаляйте тома и не используйте down -v.

```powershell
py scripts/manage.py configure
py scripts/manage.py up --connections --local-api
py scripts/manage.py verify
```

Linux/macOS: python3 вместо py. Команда up пересобирает backend из новых исходников.
В QGIS переустановите dist/qgis_mongodb.zip и полностью перезапустите QGIS.
При подключении в окне плагина должна отображаться версия backend 0.7.1.
Если версия не сообщается, контейнер backend ещё не обновлён; установка одного ZIP
плагина не обновляет контейнер.

## Geodata

Раньше использовалась QgsJsonUtils.geometryFromGeoJson, доступная лишь с QGIS 3.36,
при заявленной минимальной версии 3.28. Теперь backend готовит WKT и GeoJSON,
а плагин читает их через API, доступные в 3.28. CRS слоя явно EPSG:4326.
Все преобразования CRS и нормализация остаются в backend.

Чтение исторических записей поддерживает числовые BSON-значения/Extended JSON,
числовые строки координат, GeoJSON-строки и дополнительные метаданные GeoJSON.
При явном известном CRS геометрия преобразуется backend в WGS84. Если geometry
ошибочна, но есть корректные Longitude/Latitude, отображается точка по ним.
Ошибочная строка без корректной геометрии сохраняется в таблице с null geometry;
загрузка остальных строк продолжается. Число предупреждений показывается после загрузки.
Чтение не переписывает исходные документы. Новые записи по-прежнему проходят строгую
валидацию WGS84 Point. Неизвестный CRS и неподдерживаемые геометрии не угадываются.

Официальное описание появления API в 3.36:
https://api.qgis.org/api/3.40/classQgsJsonUtils.html

## Консоль MongoDB

Текст редактора передаётся backend без подстановки стандартного запроса. В окне
есть отдельные примеры, результат, продолжение курсора и сообщение об ошибке.
Поддержаны три формы обращения к коллекции, комментарии, regex и оформляющие методы:

```javascript
db.Patient.find({age: {$gte: 40}}).sort({age: -1}).limit(20)
db["Patient"].countDocuments({age: {$gte: 40}})
db.getCollection("Patient").distinct("age")
db.Geodata.find({"geometry.type": /^Point$/i}).limit(5).pretty()
db.Instances.aggregate([{$group: {_id: "$patient", n: {$sum: 1}}}]).toArray()
```

ObjectId/ISODate, пространственные фильтры, find/aggregate/countDocuments/distinct
и прежние проверяемые helper-операции сохраняются. pretty/toArray не отменяют
постраничную передачу: следующие строки получает кнопка продолжения.
Это ограниченный язык MongoDB-запросов, а не произвольный Python/JavaScript.
Запреты $out/$merge/$where/$function и ограничения ролей/владельцев сохранены.
Ошибки MongoDB возвращаются с кодом и ограниченным по длине описанием.

## GeoPackage

После изменения сопоставления через 0,7 секунды запускается серверная проверка
всех строк. После успешного ответа кнопка «Загрузить в MongoDB» становится активной.
Кнопка ручной проверки также сохранена. Смена сопоставления немедленно снимает
подтверждение; устаревший ответ предыдущей проверки не может включить загрузку.

Требования приходят от backend: объединяются schema required из model.json
(за исключением генерируемых ID) и прежние обязательные поля нового ввода.
model.json остаётся совместимым с историческими неполными данными. Выбранный Patient
требует passport, age, reg_date; Instances — date; Therapy — date_start, diagnosis,
ссылку patient либо Patient той же строки; Geodata — пару координат или Point таблицы.
Нельзя требовать все поля всех 17 коллекций для частичного импорта.

Необязательные поля можно не сопоставлять. NULL и пустые строки необязательных
атрибутов пропускаются. Если обязательные столбцы выбранной сущности пусты во всей
строке, сущность больше не пропускается молча: строка отклоняется до записи.
Backend проверяет типы, обязательность, внешние ключи, доступность целевых документов
и CRS. Для непространственной таблицы флажок геометрии выключен.
Ошибки показываются кратко и полностью в отдельном поле; они не вытесняют кнопки
за пределы окна. Правила лимитов и транзакций прежние: 32 МиБ, 1000 строк таблицы,
2D Point/атрибуты; транзакция на строку, пакеты по 25; повтор идентичного импорта
не создаёт дублей.
